# 零一万物2026西南生态大会 · VIP 报销材料收集

为约 30 位 VIP 嘉宾设计的手机网页。嘉宾填写资料和收款信息、按费用上传票据及行程单，工作人员集中审核，并导出 Excel 与原票据归档包用于后续报销和汇款。大会正式名称可以配置。

## 品牌界面

已使用提供的带品牌标语的零一万物透明 Logo 与“甜城 AI 链”大会主 KV，统一深绿与薄荷青色。页面顶部、页脚和后台登录均使用正式品牌素材。手机显示完整主 KV；进入费用填写与确认步骤后收起海报，便于继续填写。原图裁边及压缩后的素材位于 `public/assets/`；品牌样式集中在 `public/brand.css`。

## 本机试用

在这台电脑上双击 `start.command`，或在项目目录运行：

```sh
./start.command
```

打开终端中显示的地址：

- 嘉宾提交：`http://127.0.0.1:8765/`
- 工作人员：`http://127.0.0.1:8765/admin`

默认嘉宾邀请码为 `01AI2026VIP`，可通过 `GUEST_INVITE_CODE` 环境变量覆盖。首次启动会显示生成的管理员密码，请保存并仅交给工作人员；嘉宾只需邀请码。之后启动不再显示管理员密码，如遗失可按下方环境变量方式重新设置。

当前地址仅供这台电脑访问。请先使用虚构材料试用。

## 已实现

- 手机与电脑页面，三步填写：基本信息 → 费用与票据 → 确认提交。
- 邀请码验证；姓名、手机、单位及对接人信息，单位为必填项。新申请须填写银行卡或支付宝收款信息；不收身份证号码或第三方平台密码。
- 通过“新增费用”添加独立费用卡片，支持住宿、机票、高铁、打车及其他费用；每笔分别填写金额、用途和对应票据，可添加多笔并按类别汇总。
- PDF/JPG/PNG 票据上传；自动提取发票号码、日期、购买方名称及税号、销售方名称及税号、不含税金额、税额、含税总额共 9 个字段，允许人工核对修改。
- 打车行程单等作为补充附件上传；每笔费用还可选传最多 3 张 JPG/PNG 支付截图，补充附件和截图均不重复计算报销金额。
- 自动将填写中的资料与已上传文件关联保存到服务端草稿；同一浏览器中可继续填写，并显示保存状态和失败重试入口。
- 原始文字 PDF 自动提取；图片与扫描 PDF 使用本机 PaddleOCR，失败时可使用这台 Mac 的 Apple Vision 离线后备识别。
- 实际写入数据库和私有文件目录，生成申请编号；提交成功后提示使用本次填写的手机号查询进度，同一手机号可查看多份申请。
- 工作人员密码登录、搜索、筛选、查看原件、审核备注及状态记录；授权工作人员可查看完整收款账号。
- 工作人员可逐条删除申请，确认后移入回收站；已删除申请不计统计、导出与嘉宾查询，可在回收站恢复。票据和收款资料保留，删除与恢复记入操作日志。
- 导出真实 `.xlsx`（报销明细及申请汇总两个工作表，含供汇款的完整收款信息及支付截图关联信息）；工作人员可查看支付截图，下载的 ZIP 包含 Excel、发票、补充附件及支付截图原文件。
- 拦截重复票据内容和重复发票号码；防止重复点击提交；不同嘉宾会话不能读取他人的文件。

## 收款与费用填写

基本信息中的单位必须填写。银行卡收款须填写收款人姓名、银行卡号和开户银行，开户支行可选填；支付宝收款须填写账户实名及手机号或邮箱账号。新提交的申请必须提供一种收款方式。已有申请可能没有收款信息，工作人员需在汇款前核实补齐。

住宿、机票、高铁、打车和其他费用分别使用独立卡片。每笔填写本笔用途、金额并上传对应票据；同一类别可添加多笔。打车行程单等作为补充证明；铁路电子客票和航空电子客票行程单作为对应费用的正式票据上传，也可选传本笔费用的支付截图（仅 JPG/PNG，每笔最多 3 张）。票据、行程单和支付截图合计每份申请最多 12 个文件；补充附件和支付截图本身不增加报销金额。识别后仍须核对费用类型及金额，再查看分类汇总和申请总额。

工作人员后台及 Excel 汇款材料保留完整账号，应只交给负责审核和汇款的工作人员。网站负责收集与整理，不会自动发起转账。

## 提交后查询进度

提交成功页面会提示：之后使用本次填写的手机号查询处理进度。进度查询只需输入手机号，不需要填写申请编号；同一手机号有多份申请时，以列表分别展示每份申请的处理状态、金额、备注及时间。

查询结果只提供上述进度信息，不展示收款信息、票据、支付截图或文件下载入口。完整申请资料仍由登录后的工作人员在后台审核，不能通过手机号查询获取。

## 暂存与继续填写

填写中的基本信息、收款资料、费用及已上传文件的关联自动保存在服务端，未填完整也能暂存。可通过“上一步”“下一步”往返填写；刷新页面或关闭后再用同一浏览器打开，也可继续已成功保存的草稿。请查看界面的保存状态，失败时点击重试，显示保存成功后再关闭页面。

浏览器通过有效期 30 天的 HttpOnly 随机草稿 Cookie 找回资料，不会把个人信息或银行卡号写入 localStorage。嘉宾认证有效期为 24 小时，过期后需要重新输入邀请码，已保存的资料仍保留。删除浏览器 Cookie、换浏览器或换设备后，不能自动找回原草稿。

草稿不保存邀请码、管理员密码或同意勾选，恢复后仍须在提交前确认并勾选同意。已完成上传的文件可恢复关联，上传尚未完成时刷新或关闭页面，不保证恢复该文件。提交成功后清除对应草稿，已经提交的申请和票据仍保留供审核归档。

## 识别说明

支持「电子发票（铁路电子客票）」和「电子发票（航空运输电子客票行程单）」。铁路按票价提取报销金额，航空按合计提取，避免误取航空票价分项；航空填开日期对应开票日期，不使用乘机日期或有效截止日期。识别后仅在费用类别未选择时自动补选机票/高铁，嘉宾可核对修改。打码、缺失或无法明确定位的字段留空，不推算税额或不含税金额。

这里的自动识别用于减少录入，不代表税务验真或审核通过。系统优先读取电子 PDF 的原始文字；图片与扫描件在运行网站的电脑或服务器本地处理，票据不会发送到第三方 OCR API。提取不了的字段留空，允许手动填写；税号、金额和其他结果都需要对照原票核对。

这台 Mac 已安装并用虚构票据实际验证 PaddlePaddle 3.3.1、PaddleOCR 3.7.0，使用 `PP-OCRv5_mobile_det` 与 `PP-OCRv5_mobile_rec` 两个 CPU 模型。独立环境为 `.venv-paddle/`，模型缓存在 `.runtime/paddle/paddlex/official_models/`，就绪标记为 `.runtime/paddle-ready.json`。`start.command` 会优先使用已验证环境；本机模型已下载，识别过程可离线运行。

PaddleOCR 仓库：[PaddlePaddle/PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)。迁移至其他电脑时，先确认 Python、系统和 CPU 架构受支持，再安装 `requirements-ocr.txt`。首次准备可能联网下载官方模型，应在嘉宾使用前完成下载及票据版式验证；复制源码不会复制本机虚拟环境和模型缓存。

这台 Mac 的 Apple Vision 可在 PaddleOCR 未完成时自动后备，也可通过 `OCR_ENGINE=vision` 选择。Linux/Windows 没有 Apple Vision，须安装 PaddleOCR 才能识别图片；否则仍支持 PDF 文字提取与手动录入。扫描 PDF 最多识别前 5 页，建议每张发票单独上传。每个文件最多 15 MB，每份申请最多 12 个文件（票据、行程单及支付截图合计）。不支持 OFD，需请嘉宾提供 PDF/图片版本。

## 在其他电脑运行

需要 Python 3.11 或更新版本。项目无需前端构建环境。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --port 8765
```

macOS 的离线后备识别通过 `start.command` 准备，需要系统已有 Swift 编译器；不具备该环境时不会自动安装系统工具。

## 配置

环境变量：`EVENT_NAME`（正式大会名称）、`ADMIN_PASSWORD`（至少 12 位）、`GUEST_INVITE_CODE`（覆盖默认 `01AI2026VIP`，至少 6 位）、`DATA_DIR`（私有数据目录）、`PORT`（默认 8765）、`COOKIE_SECURE`（HTTPS 环境为 `1`）、`TRUST_PROXY_HEADERS`（默认关闭，仅在隔离的可信代理后设为 `1`）。不要把真实密码、票据、收款信息、导出材料、数据库或 `.env` 放入 GitHub；已为本机数据目录设置忽略规则。

`data/` 是真实数据存储位置，包含票据、支付截图、联系方式、收款信息及未提交草稿。复制项目给他人时只交付代码，原数据、导出材料及备份需由会务/财务管理。数据库与票据文件目前未做应用层加密；应由部署负责人设置主机权限与存储保护。保留期限和清理时间由大会财务确定，此版本不会自动清空已提交资料；草稿 Cookie 到期或被删除也不代表服务端资料已经清理。

## 删除测试申请

在工作人员后台的申请列表或详情中点击「删除」，核对确认框中的嘉宾、手机号、编号及金额后，申请移入「回收站」。回收站可查看原资料并恢复，不提供永久清空。删除后可重新上传同一张测试票据；若同张票据或发票号码已用于另一份有效申请，恢复旧记录会被阻止，须先核对重复记录。删除不会执行退款或撤销实际汇款。
